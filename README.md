# لغة لسن (LSNProg)

لغة برمجة قائمة على **منطق العربية** — نستخرج من الجذر والوزن المعنى، ونرمز إلى نبضات (0/1) حسب الورود القرآني.

> البداية: «الحمد لله» — الترتيب الأساسي للحروف حسب ورودها في القرآن.

## الفكرة

- **الجذر** = ذرة المعنى (مثل: «قرن» = الجمع والاقتران).
- **الوزن/اللاحقة** = التحويل (مثل: «ان» = الوفرة والكثرة).
- **الاشتقاق** = الجذر + اللاحقة ⇒ معنى جديد (مثل: «قرآن» = قرن + ان = الجمع والتفصيل بوفرة).
- **النبضة** = 1، **نقطة السكون** = 0، وكل حرف له كود هوفمان (الأكثر وروداً = أقصر = أقل نبض).

## التشغيل

## الأوامر

- `اشتق قرآن` — تحليل الجذر واللاحقة والمعنى
- `معنى فوق في يد الله فوق أيديهم` — اختيار المعنى حسب السياق
- `نبض قرآن` — الترميز النبضي
- `مثال` — عرض الأمثلة التأسيسية كاملة
- `خروج` — إنهاء

3. [x] تعدد المعنى والسياق + استنتاج رمزي بسيط
4. [ ] توسيع المعجم (جذور وأوزان أكثر)
