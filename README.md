# لغة لسن (LSN)

نموذج **ذكاء اصطناعي عربي رمزي-عصبي** قائم على **منطق القرآن** — يشتقّ المعنى من الجذر واللواحق والحركات، ويستنتج عبر شبكة رمزية-عصبية.

> البداية: «الحمد لله» — ترتيب الحروف حسب ورودها في القرآن.

---

## التنزيل والتثبيت

### ١) من GitHub (الأسهل — يعمل على الجوال)
نزّل الحزمة من صفحة الإصدارات:

👉 **https://github.com/Motaz3d/LSNProg/releases**

ثم:
```bash
pip install lsnprog-0.1.0-py3-none-any.whl
```

### ٢) من المصدر
```bash
git clone https://github.com/Motaz3d/LSNProg.git
cd LSNProg
pip install -e .
```

### ٣) بلا تثبيت (تشغيل مباشر)
```bash
python3 -m lsnprog استعلام "من يقطع فرعون"
```

---

## الاستخدام

```bash
lsn                          # واجهة تفاعلية (اسأل بالعربية)
lsn ويب                      # واجهة ويب بسيطة (تفتح في المتصفح — تعمل على الجوال)
lsn استعلام "من يقطع فرعون"   # استعلام الشبكة
lsn مثال                     # الأمثلة التأسيسية كاملة
lsn تعلم                     # عروض التعلّم من القرآن
lsn حركات                    # الحركات وتمييز معاني «علم»
lsn صورة                     # الصورة الرمزية لـ«روح»
lsn --version                # الإصدار
```

### واجهة الويب
```bash
lsn ويب
# افتح: http://127.0.0.1:8000
# من الجوال (نفس الشبكة): http://<عنوان-جهازك>:8000
```

## الفكرة

- **الجذر** = ذرة المعنى (مثل: «قرن» = الجمع والاقتران).
- **الوزن/اللاحقة** = التحويل (مثل: «ان» = الوفرة، «ون» = التكثير).
- **الحركات** = تمييز المعنى (عِلْم / عَلَم / عَلَّمَ)، بأوزان ثنائية (سكون=0، فتحة=1، كسرة=10، ضمة=11).
- **النبضة** = 1، **نقطة السكون** = 0 (كود هوفمان حسب الورود القرآني).
- **الشبكة الرمزية-العصبية** = عقد (مفاهيم) + روابط (علاقات) + انتشار تنشيط.
